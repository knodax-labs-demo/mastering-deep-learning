# Mastering Deep Learning – Companion Code Repository

Welcome to the official code repository for **Mastering Deep Learning: From Fundamentals to Advanced AI Applications** by **SK Singh**.

This repository contains the source code, Jupyter notebooks, datasets, and hands-on lab exercises used throughout the book. The examples are designed to help readers understand deep learning concepts through practical implementation using Python and PyTorch.

---

## About the Book

*Mastering Deep Learning* provides a comprehensive journey through modern deep learning, beginning with neural network fundamentals and progressing to advanced topics such as:

- Convolutional Neural Networks (CNNs)

- Recurrent Neural Networks (RNNs)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Units (GRU)
- Natural Language Processing (NLP)
- Word Embeddings
- Transformers
- Attention Mechanisms
- Large Language Models (LLMs)
- Generative AI
- Transfer Learning
- Production Deep Learning with PyTorch

## Prerequisites

To run the examples, install:

- Python 3.10 or later
- Jupyter Notebook or JupyterLab
- PyTorch
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Installation

Clone the repository:

```bash
git clone https://github.com/knodax-labs-demo/mastering-deep-learning.git
cd mastering-deep-learning
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment:

### Windows

```bash
venv\Scripts\activate
```

### macOS/Linux

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
